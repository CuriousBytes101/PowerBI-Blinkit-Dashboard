# Blinkit Sales Dashboard | Power BI

##  Project Overview

This project is an interactive **Blinkit Sales Dashboard** built using **Power BI** to analyze sales performance, product categories, outlet characteristics, and customer ratings.

The dashboard provides insights into overall sales, item performance, outlet size, outlet type, outlet establishment trends, and fat content distribution.

---

## Project Objective

The main objective of this project is to:

* Analyze overall sales performance.
* Identify top-performing item categories.
* Compare sales across different outlet types and outlet sizes.
* Analyze sales trends based on outlet establishment year.
* Understand the distribution of Low Fat and Regular products.
* Track important KPIs such as Total Sales, Number of Items, Average Sales, and Average Rating.

---

##  Tools Used

* **Microsoft Excel** – Dataset storage and initial data handling.
* **Power BI** – Data cleaning, transformation, analysis, and dashboard creation.
* **Power Query** – Data transformation and cleaning.

# Dataset Information

The dataset contains information related to Blinkit products, sales, and outlet characteristics.

| Column Name               | Description                                      |
| ------------------------- | ------------------------------------------------ |
| Item Fat Content          | Indicates whether the item is Low Fat or Regular |
| Item Identifier           | Unique identifier for each item                  |
| Item Type                 | Category of the item                             |
| Outlet Establishment Year | Year in which the outlet was established         |
| Outlet Identifier         | Unique identifier for each outlet                |
| Outlet Location Type      | Location tier of the outlet                      |
| Outlet Size               | Size of the outlet                               |
| Outlet Type               | Type/category of outlet                          |
| Item Visibility           | Visibility percentage of the item                |
| Item Weight               | Weight of the item                               |
| Sales                     | Sales generated by the item                      |
| Rating                    | Customer rating for the item                     |

# Data Cleaning and Transformation

Data cleaning and transformation were performed using **Power Query**.

### Item Fat Content Standardization

The `Item Fat Content` column contained inconsistent values.

The following transformations were performed:

| Original Value | Updated Value |
| -------------- | ------------- |
| LF             | Low Fat       |
| reg            | Regular       |

Additionally:

* Errors were removed from the dataset.
* Inconsistent categorical values were standardized.

## Key Insights

Total Sales: The business generated approximately $1.20M in total sales.
Total Items Sold: Around 8.52K items were sold, with an average sales value of $141.
Average Rating: Products received an average customer rating of 3.9/5.
Outlet Establishment: Sales peaked at approximately $205K in 2018, while the lowest sales were around $78K in 2012.
Top Item Categories:
Fruits & Vegetables – $178K
Snack Foods – $175K
Household – $136K
Frozen Foods – $119K
Dairy – $101K
Outlet Performance: Supermarket Type1 contributes the highest sales at approximately $0.79M, significantly higher than the other outlet types.
Outlet Size: Medium outlets generate the highest sales ($507.90K), followed by Small ($444.79K) and High ($248.99K).
Fat Content: Low Fat products contribute approximately $776.32K, compared with $425.36K from Regular products.
Outlet Tier: Tier 3 outlets generate the highest sales, followed by Tier 2 and Tier 1 outlets.
Overall, Fruits & Vegetables and Snack Foods are the strongest product categories, while Supermarket Type1 and Medium-sized outlets are the strongest outlet segments.
